# Iris – Auxiliaire de vie numérique

Landing page présentant les outils et services numériques destinés aux auxiliaires de vie et aux personnes accompagnées.

## Présentation

La page d’accueil propose une animation de cartes qui se déploient en éventail puis se rangent pour être facilement consultables, y compris sur téléphone.

Chaque carte correspond à un service et contient un QR code local.

## Fichiers

- `index.html` (ou `iris_landing.html`) : page principale
- `qr_aides.png`
- `qr_atelier.png`
- `qr_aase_app.png`
- `qr_aase_site.png`
- `qr_taches.png`
- `livret_taches_A6.pdf` (à ajouter)

## Utilisation

1. Placez tous les fichiers dans le même dossier.
2. Ouvrez `index.html` dans un navigateur.
3. L’animation se lance automatiquement.
4. Cliquez sur une carte pour l’agrandir et afficher le QR code en grand.
